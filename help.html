Adding objects

Use the Add menu or the left panel to add cubes, spheres, cylinders, toruses, cones, planes, lights, and cameras.

Materials

Select a mesh, then use the inspector to edit its color, opacity, metalness, roughness, and wireframe display.

Import & export

Import and export JSON scenes, OBJ meshes, and glTF/GLB models using the File menu.

Editor scope

YJD Editor is designed for rapid scene layout, level blocking, lighting tests, and simple 3D prototypes. It does not provide vertex, edge, or face modeling; UV editing; sculpting; rigging; or animation authoring.
